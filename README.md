# COSMOS - Space Dashboard

A space-themed dashboard built with vanilla JavaScript that pulls live data from public space APIs: NASA's Astronomy Picture of the Day, upcoming rocket launches, and planet information.

## Features

- Astronomy Picture of the Day from the NASA APOD API
- Upcoming launch schedule fetched from a launch API, with a detail modal
- Planet data with relative-gravity calculations
- Responsive sidebar navigation
- Live data rendering with fetch and async UI states

## Tech stack

- Vanilla JavaScript
- HTML5, CSS3
- NASA APOD and open space-data APIs

## Getting started

Open `index.html` in a browser - no build step needed.
